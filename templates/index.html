① 粘贴 AI 回答 / Markdown

为什么直接粘贴会乱？点开看原因
  • 网页的字体/字号写在 CSS 类里，Word 不认类，粘贴时全部丢掉； 只剩浏览器默认的宋体字号。
  • 标题在网页里可能只是一个"加粗的大字"，不是 Word 的"标题 1"， 所以导航窗格空白、目录生成不出来。
  • 公式在网页里是一堆 span 拼的字符，Word 收到的是乱码文本， 不是可编辑公式。
  • 表格在网页里靠 CSS 边框，Word 收到后边框和列宽全丢。
